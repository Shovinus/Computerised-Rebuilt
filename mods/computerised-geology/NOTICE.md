# Attribution and port status

Computerised OreGen is a modified, modern port derived from CustomOreGen,
originally created by JRoush and later revived by lawremi and contributors.
The upstream project is licensed under the Artistic License 2.0.

This version replaces the Minecraft and Forge integration layer, uses modern
registry IDs and tags, and rasterises deterministic structures one chunk at a
time. It currently implements bounded uniform and normal probability
distributions, weighted block mixtures, ellipsoidal motherlodes, segmented
branches, recursive forks, density control, height control, biome tags, and
replaceable-block tags.

Upstream source: https://github.com/lawremi/CustomOreGen
